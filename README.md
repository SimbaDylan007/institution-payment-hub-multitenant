
# Institution Payment Hub

## Project info

A dashboard application for managing student payments at educational institutions.

## How to run this project

Follow these steps:

```sh
# Step 1: Clone the repository.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deploying this project

You can build the project for production using:

```sh
npm run build
```

This will create optimized files in the `dist` directory that you can deploy to any static hosting service.

## Custom domain setup

To connect a custom domain to your application, update your DNS settings with your hosting provider.
